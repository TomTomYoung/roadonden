# ロードンデン — 商店街の向こうへ

商店街と脇道、雑居ビルとアパート群。窓の向こうで続く100人の暮らしを観察し、認識と行動の行き違いをほどく探索アドベンチャーです。

現在は **30棟・329地点の全体マップで、35人と犬の物語**を遊べます。六区間の商店街と裏通り、南側のアパート街を歩き、各人の事情を聞き、現物を運び、本人と相談して暮らしを進めます。夕食の三経路、鍵と見回り、母娘の茶、手紙と呼鈴、帰路と着替え、舞台と枕、親子の寝かしつけ、名札と郵便、夜回りと訂正図、エレベーターの案内、演奏と休息を実装しています。

今回の `town-0.8.0` ではジャイルズ・エルシー・レナを加え、排気の確認、寝具の小分け乾燥、初釜と試食、指定時計との照合まで進められます。乾いた予備布で着替える別解、防振の当て物を共同試験して練習と休息を重ねる別解、借用品の返却にも対応します。

街の規模は戸越銀座の商店街と周辺住宅街を基準に拡張中です。素材208点をドット絵へ切り替え、全体表示・ドラッグ・ホイール・小地図・区間選択・場所名検索を追加しました。100人分のシナリオと初期配置案があり、残る65人の動作と結末は未実装です。まずこの全体マップ上で全100人を完成させ、その後にMOON型のエリア別探索へ進みます。[ハンドオフ](doc/handoff.md) と [街の配置](doc/09-town-layout.md) に現状を記録しています。

## 遊び方

リポジトリをダウンロードし、ルートの **`index.html` をブラウザで開いてください**。Node.js、サーバー起動、ネット接続は不要です。公開ホスティングURLはまだありません。

- 部屋・廊下・階段をクリック、または方向キー / WASDで歩く。
- 近くの人の名前をクリック、またはE / Enterで話す。
- ドラッグで地図を移動、ホイールまたは＋ / −で拡縮。「全体」で街を見渡し、「あなたへ」で追従。小地図と区間名から表示を移動できます。
- Iで持ち物、Jで手帳、Mで歩いた場所、Escで一時停止。
- 会話・手帳・保存画面の間は時間が止まる。「少し待つ」は同じ世界を4倍速で進める。

スタートはA棟101の管理人室です。二階の201号室にはフィンチ家、雑居ビル一階には食品店と靴修理店、二階には子どもの活動室があります。

手動保存3枠、自動保存2世代、JSON書出し・読込みに対応しています。保存領域が使えない場合は失敗を表示するため、JSONで記録を持ち出せます。**直前の全体マップ版は [legacy/town-0.7.0.html](legacy/town-0.7.0.html) で再開できます。それ以前の版は保存画面から選べます。前の全体マップ版のセーブは [legacy/town-0.4.0.html](legacy/town-0.4.0.html)、旧・三棟版のセーブは [legacy/block-0.3.0.html](legacy/block-0.3.0.html)、旧・街歩き版のセーブは [legacy/dinner-0.2.0.html](legacy/dinner-0.2.0.html) で再開**してください。新版と旧版の保存枠は別で、新版への自動変換はしません。

## 素材と開発

建物11点、内装32点、人物と犬102点、小道具63点、計208点のドット絵を画素単位のSVGで用意しています。`public/pixel-assets/manifest.json` が台帳、`npm run assets` が再生成です。旧53点は `public/assets/` に残しています。画像はすべて単体HTMLへ埋め込みます。全100人の固有動作と音、細かな室内自由歩行、実機のタッチ・ゲームパッド対応は未完了です。

Node.js 24以上で `npm ci`、`npm run verify`。TypeScript 5.9.3とesbuild 0.25.11で型検査、自動テスト86件、ビルドを行います。`index.html` と開発検査用の `inspector.html` は生成物もコミットします。

Playwright環境では `node scripts/browser-dinner-check.mjs` で本編、`node scripts/browser-check.mjs` で検査画面を確認します。必要なら `PLAYWRIGHT_MODULE` と `CHROMIUM_EXECUTABLE` を指定します。通常プレイには不要です。
