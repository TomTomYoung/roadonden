# ロードンデン街の人々

産業革命期の英国を思わせる架空の街で、100人の住民の暮らしを観察し、認識と行動の行き違いをほどいていく探索アドベンチャーです。

現在は **Phase 1の実行基盤を実装した段階**です。時計、認識と伝達、行為、予約、受渡し、復旧、達成履歴、保存を、開発用の検査画面で確認できます。本編100人のゲーム、夕食シナリオ、完成素材、公開プレイ用URLはまだありません。

## 検査画面を開く

リポジトリを取得し、ルートの **`index.html` をブラウザで開いてください**。実行時のNode.js、サーバー起動、ネット接続は不要です。3人の検査役は本編100人とは別です。

「調べる」「行為を開始」「知らせる」で操作を予約し、「1更新」「10更新」「100更新」または「進める」で時間を進めます。画面内の「検査の例」に手順があります。

手動保存3枠・自動保存2世代・JSON書出し/読込みを備えます。ブラウザの設定で保存領域が使えない場合は失敗を表示します。JSON書出しを利用できます。直接起動を確認したのはChromiumです。

## 開発

Node.js 24以上で `npm ci`、`npm run verify` を実行します。型検査、基盤テスト、単体HTMLのビルドを順に行います。変更後の `index.html` もコミットしてください。TypeScript 5.9.3、esbuild 0.25.11を固定しています。

ブラウザ検査はPlaywrightを利用できる環境で `node scripts/browser-check.mjs` を実行します。必要なら `PLAYWRIGHT_MODULE` にインストール先、`CHROMIUM_EXECUTABLE` にChromiumの実行ファイルを指定できます。通常起動には不要です。

実装範囲と検証結果は [doc/foundation-status.md](doc/foundation-status.md)、次の作業は [doc/handoff.md](doc/handoff.md) に記載しています。

仕様と次の作業は [doc/README.md](doc/README.md) から参照してください。設計の基準は「認識と行動からの再設計」および対応する100人の人物設定です。
