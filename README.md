# ロードンデン街の人々

産業革命期の英国を思わせる架空の街で、100人の住民の暮らしを観察し、認識と行動の行き違いをほどいていく探索アドベンチャーです。

現在は **11人と犬が暮らす「夕食編」の試作**を遊べます。靴の回収、貸し靴、材料の配達から家族の夕食へ進めます。周辺住民の用事は独立して残り、食後にも取り組めます。残り89人と完成素材は制作途中です。

## 遊び方

リポジトリをダウンロードし、ルートの **`index.html` をブラウザで開いてください**。閲覧にNode.js、サーバー起動、ネット接続は不要です。公開プレイ用のホスティングURLはまだありません。

- 道・建物をクリック、または方向キー / WASDで歩く。
- 近くの人の名前をクリック、またはE / Enterで話す。
- Iで持ち物、Jで手帳、Mで歩いた道、Escで一時停止。
- 会話・手帳・保存画面を開いている間、街全体の時間が止まる。
- 「少し待つ」は実際の街の更新を4倍で進める。行為を完了扱いにするボタンではない。

手帳には自分で見聞きしたことと、確認した達成が残ります。手動保存3枠、自動保存2世代、JSON書出し・読込みを利用できます。自動保存は通常速度で約2分遊ぶごとです。ブラウザの保存領域が使えない場合は失敗を表示するため、JSON書出しを利用してください。

PCのChromiumによる直接起動を検証しています。道は区間単位の仮マップです。細かな室内自由歩行・視聴覚、完成素材、実機のタッチ・ゲームパッド対応はまだありません。

## 開発と検査

Node.js 24以上で `npm ci`、`npm run verify` を実行します。型検査、自動テスト、ビルドを順に実施します。TypeScript 5.9.3、esbuild 0.25.11を固定しています。

`src/game/` と `src/content/dinner.ts` が本編です。ビルドで作る `index.html` と `inspector.html` の両方をコミットしてください。`inspector.html` は3人の検査役と内部情報を使う開発画面で、本編人物とは別です。

Playwrightのある環境では `node scripts/browser-dinner-check.mjs` で本編、`node scripts/browser-check.mjs` で検査画面を確認できます。必要なら `PLAYWRIGHT_MODULE` と `CHROMIUM_EXECUTABLE` を指定します。通常プレイには不要です。

実装と検証の範囲は [doc/dinner-status.md](doc/dinner-status.md)、次の着手点は [doc/handoff.md](doc/handoff.md)、全体仕様は [doc/README.md](doc/README.md) を参照してください。人物の正本は再設計版の100人の原文です。
