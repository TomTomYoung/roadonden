## 制作方針

街の規模感は戸越銀座の商店街と周辺住宅街。現画面は全体マップで、素材はドット絵です。まずこの全体マップで100人・十場面・別解・共同作業・達成後の暮らし・保存・結末を完成させます。その後にMOONを基準としたエリアごとの探索シーンへ進み、必要ならPhaserを検討します。現在はCanvasを継続しています。

30棟・327地点、六区間の商店街・裏通り・住宅路を保持しています。現在の棟数へ全員を押し込む制約はありません。O棟の共用エレベーターは荷物用昇降機と独立した初期経路です。C044の案内と運行の描画は未実装です。

## 今回の実装

**動作実装は23人と犬**。前版の15人に、C013ネル、C014サム、C015アイリス、C017ヘスター、C020フィン、C021ビー、C075テオ、C084オスカーを追加しました。残る77人の動作と全員の結末は未実装です。100人の基礎シートや配置案があることを、動作完成に数えません。

- **便りと呼鈴**：側窓でネルに用件を伝え、了承を受けて未開封の便りを運ぶ。本人が読み、刺繍を始める。修理は別に、外と内の観察をオスカーへ伝え、本人が事情を説明し、立入りの合意後に接続する。外側から引き、内側の二人が音を確かめてから謝罪する。便りと修理はどちらを先にしても進む。
- **足場と着替え**：サムの待つ約束をアイリスへ届け、着替え後の窓の札で通行する。別解は、固定した外梯子を使い先にサムが帰る経路と、アイリスが静かな共用室で着替える経路。清掃道具と折畳み梯子の現物を地上へ運んで返す。エルシーC034の予備布を借りる第三経路は未実装。
- **枕と舞台**：本人の縫い印と返却先をテオが現物と照合。舞台工房の予備布で代用品を作り、試して棚と返却札を点検する。枕は主人公が寝室へ運ぶ。ヘスターは自分の上着を畳んで試す別解でも、寝具を整え、横になり、眠る。先に眠った後の枕返却も可能。
- **親子の眠り**：主人公の観察をビーへ伝え、本人がゆりかごを平らな床へ置く。または本人が抱く。落ち着き、入眠、一定時間の見守りを経てフィンが達成。ビーはその後に子を寝かせ、茶を入れ直して休む。フィンには移動・会話・同意・成人の判断規則を割り当てない。

閉じた窓は主人公も通り抜けません。地図からの経路選択は現在の扉条件で迂回し、各区間の開始時に再確認します。眠ったヘスターとフィンは、同じ場所で様子を観察して後から達成を確認できます。本人の発言や覚醒を生成しません。

**ドット絵は177点**。建物11、内装31、人物と犬102、小道具33です。枕・クッション・手紙・梯子・固定索・道具袋・ゆりかご・敷物・呼鈴を追加しました。フィンの姿を乳児へ描き直し、寝姿・抱かれた状態・呼鈴の接続・窓の札・所持物を表示します。全員の固有アニメーションと音は未完成です。旧53素材は保持しています。

## 起動とファイル

ルートの `index.html` を直接開きます。プレイにサーバーやNode.jsは不要です。公開ホスティングURLはありません。`inspector.html` は基盤検査画面です。

- `src/content/rooms-and-sleep.ts`：今回の8人。人物と現物の登録を歩行カタログ生成前に行い、会話・観察・行為を後から組み立てます。
- `src/content/dinner.ts`：既存の夕食・鍵・茶、共通の行為生成、接続経路と通行条件。各人物の判断は本人の観測・伝聞・同意から行います。
- `src/content/town-layout.ts` / `resident-placements.ts`：全体地理と全100人の配置台帳。最新配置は `doc/09-town-layout.md` を参照。
- `src/core/engine.ts`：新しい `observeCompletion` は、定義された観察条件と同席を検査し、既に起きた達成を知るだけです。達成そのものは生活行為のイベントだけで発生します。
- `src/game/renderer.ts` / `scripts/make-town-assets.mjs`：描画と画素格子の素材生成。`npm run assets` で再生成。
- `tests/rooms-and-sleep.test.mjs`：別解、前後順、無断取得・立入りの拒否、親子の異なる達成時刻、途中保存、後日の観察。

内容版 `town-0.5.0`、保存形式2、保存枠 `roadonden:town:v5:`。前の全体マップ版は `legacy/town-0.4.0.html` と `roadonden:town:v4:` で保持します。旧三棟版と旧街歩き版も保持し、各版の保存画面から以前の版へ進めます。旧セーブの自動変換はしません。今回、原文と旧素材は変更していません。

開発はNode.js 24以上で `npm ci`、`npm run verify`。ブラウザは `scripts/browser-dinner-check.mjs` 、`scripts/browser-rooms-check.mjs` と `scripts/browser-check.mjs`。型検査・64件の自動検査・ビルドが成功し、閉じた窓の経路修正後は該当する2経路を再検査しました。ブラウザは本編15件・追加5件・検査画面10件を確認しました。結果と限界は [実装状況](dinner-status.md) に記録します。生成HTMLとSVGもコミットします。
