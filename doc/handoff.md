# ハンドオフ

更新: 2026-10-19 JST / town-0.8.0。対象: TomTomYoung/roadonden。

## 制作方針

街の規模感は戸越銀座の商店街と周辺住宅街。現画面は全体マップ、素材はドット絵です。まずこの全体マップで100人・十場面・別解・共同作業・達成後の暮らし・保存・結末を完成させます。その後にMOONを基準としたエリアごとの探索シーンへ進み、必要ならPhaserを検討します。現在はCanvasを継続します。

30棟・329地点、六区間の商店街・裏通り・住宅路です。パン屋裏に排気口と小分けの物干しの2地点を追加しました。現在の棟数へ全員を押し込む制約はありません。O棟の共用エレベーターと荷物用昇降機は独立しています。共用エレベーターの往復案内は動きますが、完全な呼出し・開閉扉・定員の設備モデルは未実装です。

## 今回の実装

**動作実装は35人と犬**。前版の32人にC026ジャイルズ、C034エルシー、C057レナを追加しました。残る65人の動作と全員の結末は未実装です。100人の基礎シートや配置案を、動作完成に数えません。

- **干し場と初釜**：排気口の布と空気の通りを主人公が調べ、エルシーとジャイルズへそれぞれ伝える。双方が了承して同席し、布と通り道を直接見比べる。エルシーが湿った寝具を二束とも取り込んで運び、一束ずつ掛け、時間を置いて乾きを確かめて取り込む。二束を地上の棚まで運び、畳んで別に達成する。ジャイルズは空いた排気の通りを確かめて店へ戻る。
- **パン屋の二経路**：残った焼け跡と目盛板のずれを本人へ伝える。従来の焼き色・底の響き・試し生地で確かめるか、レナの通常貸出の確認具を主人公が運び、ジャイルズ本人が固定目盛と取付穴を照合して板を直す。確認具の貸出はレナの時計の仕事が終わる前から利用できる。既に店にある一釜分の粉で焼き、主人公が希望した客として一切れを受け取り、実際に食べ、本人が感想を聞いて達成する。残り三切れの通常の受取りを残し、なくなれば終了する。一般の販売・代金・ニーナの買物はまだ扱わない。
- **指定時計と返却棚**：レナは三つの時計を互いに合わせ直している。主人公が依頼票の「郵便室の正面入口の時計」という指定を読み、本人へ伝える。レナが持参時計を持って現地へ歩き、指定された時計を直接照合してから工房へ戻る。その基準で三つを調整・記録し、計器と結果を棚へ運んで試験を終える。三つが偶然同じ表示になっただけでは達成しない。その後は談話室で休み、通常の貸出棚と返却口を残す。
- **アイリスの予備布の別解**：本人が目隠しを了承し、主人公がエルシーの貸出用の乾いた布を記帳して借り、手渡す。アイリスが自分で掛けて着替え、帰路の了承を掲示し、布を外して畳んでから外出する。主人公は外出後でも布を回収し、地上の返却口へ戻せる。濡れた寝具とは別の現物で、洗濯の達成を待たない。従来の待つ約束と別室の経路も保持する。
- **ローズとノアの防振材の別解**：従来と同じ共同試験で原因を確かめた後、双方が当て物の試験を了承する。主人公がレナの通常貸出品を借りて脚へ敷き、二人が隣室で同じ短い試奏の時刻と振動を確認する。結果を聞いて全員が同意してから、ローズは一曲を通し、ノアは時計を掛け直してその間に休む。演奏と隣室へ伝わる振動を別に扱い、設置しただけでは達成させない。一曲の終了を連絡して約束札を残し、休息を確認する。演奏終了後に当て物を外し、返却しても眠った人の達成を消さない。先に借りた未使用の品も返却できる。従来の時間を分ける経路は保持する。

布・当て物・確認具は所有者、現物の所在、借主、返却先、借用と返却時刻を別に記録します。貸主の仕事が未完了なら本人と合意して借り、完了後は棚の貸出案内に従って記帳します。借用・返却のために貸主の元の問題を再開しません。乾いた覆い布も寝具とは別に保管していますが、覆い布を使う市場の場面は未接続です。

C042ウォルターが網を移して広い物干しを空ける別解は未実装です。今回は少量ずつ干す経路を実装しました。C026の目盛の経路では、レナの確認具を受け渡し、本人が確認・取付けを行う通常サービスとして接続しています。

## 継続する仕組み

歩行は隣接する地点間で時間を使います。同行者は同じ行為で移動し、移動中の会話・現地観察を止めます。直接中断なら出発地点に残り、通常UIの取消しなら今の区間を終えて止まります。保存は残り時間ごと復元します。エレベーターは同じ縦軸と共有する乗車資源を使い、地図からの移動は空きを待って続けます。

街で観測したことはその場の本人の認識へ届け、遠くの人物へ自動共有しません。物理的に正しいことと、本人が知って行動を選ぶことを分けています。乳児は今回の新しい手掛かりでも成人の推論をしません。達成した人の通常サービスを残し、後続のために達成を取り消しません。

操作欄はその場の人物と行為の変化で更新します。遠くの住民の行動で会話ボタンを連続して作り直しません。同行と共同作業は必要な人物・設備が空いたときに選べます。
