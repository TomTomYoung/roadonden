## 開き方と再検証

ルートの `index.html` をブラウザで直接開けます。外部通信・開発サーバー・Node.jsは閲覧には不要です。これは開発用検査画面で、検査役3人を本編人物へ読み替えないでください。

開発時はNode.js 24以上で `npm ci` と `npm run verify` を実行します。ビルドは `scripts/build.mjs` からルートの `index.html` を再生成します。生成済みHTMLもコミット対象です。ブラウザ検査はPlaywrightのある環境で `node scripts/browser-check.mjs` を実行します。

型検査、基盤テスト25件、単体HTMLビルド、Chromiumでの10項目のブラウザ操作確認が成功しています。保存は手動3枠、自動2世代、JSON入出力を確認しました。保存領域拒否・破損JSON・未知版・不整合状態で成功を偽らず、現在のゲームを維持します。本編T01〜T18はまだ未実施です。

## 維持する要件

100人の生活目的とID、通常の代案、初期から複数の入口、達成の不可逆性、達成者への新しい必須依頼の禁止、画面外での同じ進行、伝達されない情報の非共有を維持します。時間・物・人の移動を巻き戻す共同作業リセットは使いません。

物は一つの所在、所有者と所持者は別、数量と消費は実行の証拠に対応させます。情報を得たことと、信じたこと、同意したこと、実行したことを同じフラグにしません。検査役では初版の伝聞更新を使っていますが、人物ごとの信用と反応は本編データ化で拡張します。

再設計版のノラ、オーウェン、キット、ベンを基準にし、旧案の人名・依存図を持ち込まないでください。原文にない値には試作の根拠を付けます。人物の目的や別解を変える必要が出た場合は先に具体的な矛盾を報告します。

## 未実装と注意点

本編11人と犬・全100人、詳細な視聴覚、貸借台帳、数量の分割併合・補充、時刻表、複数段階の共同場面、完成素材と音、通常ゲームUI、公開ホスティングは未実装です。保存移行・100人負荷・長時間ログ最適化もまだです。

保存は `schemaVersion: 1` / `contentVersion: foundation-0.1.0` で、検査用の内容と一対です。スキーマまたはコンテンツを変えたら版を変え、移行を実装しない場合は明示的に拒否します。現行の検査役を本編の人物番号へ自動対応させないでください。

現在の検査画面には内部情報・住民の直接操作があるため、そのままゲーム完成版として公開しないでください。公開URLはまだありません。`index.html` の直接起動を確認したのはChromiumで、Windows実機やChrome/Edgeの各環境で検証したとの主張はしません。
