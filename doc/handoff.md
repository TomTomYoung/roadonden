更新: 2026-10-18 / town-0.6.0。対象: TomTomYoung/roadonden。

## 制作方針

街の規模感は戸越銀座の商店街と周辺住宅街。現画面は全体マップ、素材はドット絵です。まずこの全体マップで100人・十場面・別解・共同作業・達成後の暮らし・保存・結末を完成させます。その後にMOONを基準としたエリアごとの探索シーンへ進み、必要ならPhaserを検討します。現在はCanvasを継続します。

30棟・327地点、六区間の商店街・裏通り・住宅路。現在の棟数へ全員を押し込む制約はありません。O棟の共用エレベーターは荷物用昇降機と独立した初期経路です。C044の案内と運行の描画は未実装です。

## 今回の実装

**動作実装は26人と犬**。前版の23人にC012ヒュー、C016エイベル、C090ベアトリスを追加しました。残る74人の動作と全員の結末は未実装です。100人の基礎シートや配置案を、動作完成に数えません。

- **二棟の名札**：現在の配置のA棟301とH棟301。エリアスとアイリス本人から住所を聞き、届ける了承を得て、本人が書いた確認札を預かる。両廊下の古い留め跡を調べ、ヒューへ伝えると塗り直しを止める。確認札二枚を現物で渡し、照合を頼む。ヒューは両棟を調べ、取り違えた札を運んで交換し、読み直して確認札を各廊下に残す。両住民の帰宅・外出の前後で進められ、私室へ立ち入らない。
- **正面の扉**：ベアトリスの開け方でエイベルと共同試験する。主人公は下端の擦れを見てエイベルへ伝える。エイベルが下端を調整し、ベアトリスが自分で開けて実際に入る。それを見届けてエイベルの達成。扉を直すだけでは達成しない。通常の鍵相談は最初から利用できる。
- **郵便の仕事**：本人は別入口を先に選べる。台の高さ・足元・袋の配置を相談し、主人公が2階から担当札付きの郵便袋を未開封で運ぶ。台を調整し、本人が膝と手の届く範囲を確かめる。本人が仕分けて一束を受渡し棚へ送るまでがベアトリスの達成。袋の先届けも可能。ネルの便りとは別の現物。
- **仕事後の入館**：受渡し記録、外回り、次の入館を継続する。仕事の後に正面扉を修理した場合も、通常の入館で開閉・通行を確かめる。ベアトリスを再び未達成に戻したり、試験だけのために呼び出したりしない。

郵便室の二入口・仕分け台・受渡し棚を1階へ配置しました。共用階段は受渡し棚側から続きます。ベアトリスは階段へ進めず、1階の実際の接続を使います。全街区の段差やエレベーター運行が完成した意味ではありません。

既存の夕食三経路、元の鍵と予備鍵、母娘の茶、便りと呼鈴、足場の帰路と着替え、枕と舞台、親子の眠りを保持しています。アイリスのC034の予備布経路は未実装です。眠ったヘスターとフィンは、起こさず現地観察で達成を知れます。

**ドット絵は186点**。建物11、内装32、人物と犬102、小道具41。入口内装と、棟名札・確認札・郵便袋・束・開閉する扉・仕分け台を追加しました。ベアトリスは車椅子の6姿勢に描き直し、戸・台・所持物は実際の状態から表示します。全員の固有アニメーションと音は未完成。旧53素材は保持しています。

## 起動とファイル

ルートの `index.html` を直接開きます。サーバーやNode.jsは不要です。公開ホスティングURLはありません。`inspector.html` は基盤検査画面です。

- `src/content/postal-and-plates.ts`：今回の3人。登録は歩行カタログ生成前、行為の組立ては共通ヘルパーの定義後です。
- `src/content/rooms-and-sleep.ts`：前版の8人。観測者の既定値で乳児を除外する処理は、新しい手掛かりの登録後にも適用します。
- `src/content/dinner.ts`：夕食・鍵・茶、共通の行為生成、接続経路と通行条件。住民の選択は本人の観測・伝聞・合意から行います。正面通行の効果は実際の移動成功時だけです。
- `src/content/town-layout.ts` / `resident-placements.ts`：地理と全100人の配置台帳。`doc/09-town-layout.md` に現在の場所と接続数を出力済み。
- `src/game/renderer.ts` / `scripts/make-town-assets.mjs`：描画と画素格子の素材生成。`npm run assets` で再生成。
- `tests/postal-and-plates.test.mjs`：本人確認・同意・物の移転・遅い修理・順序・途中保存・段差のある経路の拒否。

内容版 `town-0.6.0`、保存形式2、保存枠 `roadonden:town:v6:`。v5は `legacy/town-0.5.0.html` と `roadonden:town:v5:` で保持します。v4・三棟版・旧街歩き版も保持し、保存画面から開けます。旧セーブの自動変換はしません。原文と旧素材は変更していません。

開発はNode.js 24以上で `npm ci`、`npm run verify`。ブラウザ検査は `scripts/browser-dinner-check.mjs`、`browser-rooms-check.mjs`、`browser-postal-check.mjs`、`browser-check.mjs`。型検査・71件の自動検査・ビルドが成功しました。ブラウザは本編15件・部屋と眠り5件・郵便室4件・検査画面10件、計34件が成功しました。描画調整後にも実際のセーブを再読込みし、入口と作業台の表示、全186素材、例外がないことを確認しました。生成HTMLとSVGもコミットします。
