# 街の配置と実装範囲 — town-0.7.0

2026-10-18。30棟・327地点、六区間の商店街、裏通り、南側住宅路を実装しました。各地点は主人公が通常の操作で歩いて到達できます。全100人分の初期位置と目的地を先に割り当てていますが、動作実装済みは32人です。未実装68人を無目的の立ち人として出したり、人数だけを達成扱いにしたりしません。

戸越銀座程度の街を目標にした最初の拡張です。現在の棟数を完成時の上限にはしません。各人の受渡し、巡回、同時作業、視線・音の届き方、部屋の詳細を実装しながら追加します。初期位置と目的地の接続だけで、100人の生活動線が完成したとは数えません。

## 新たに遊べる経路

エリアスの上着の特徴を聞き、本人の受取りの了承を得てベスに伝えます。ベスが現物を照合してから鍵を預かり、エリアスへ渡すと、本人が廊下と階段を歩き、自分で扉を開け、椅子に座ります。鍵を手にした瞬間を帰宅達成にしません。

別解ではエリアスと管理人室で待つ約束をし、その約束をドーラへ伝えます。二人が実際に管理人室へ来てから予備鍵を受け渡し、エリアスが入室します。ドーラは帰宅を確かめて休憩室へ歩いて休みます。札や約束を作っただけで、知らない相手が移動する仕組みにはしません。予備鍵は301の返却口へ戻ります。

アグネスの話をベスへ伝えると、ベスは上着と記録を保管箱まで実際に運び、店へ戻って戸締まりをして、母の部屋へ歩きます。二人が同じ卓で茶を飲んで、双方の目的が達成されます。先にこの経路を終えても、保管箱で本人の説明と上着を照合して鍵を取り出せます。予備鍵で先に帰宅していても、元の鍵を返却口へ届けられます。

## 共用エレベーター

O棟の1階と2階を接続し、初期状態から主人公が使えます。荷物用昇降機や搬入の達成を要求しません。今回実装したのは移動経路で、ハリエットの案内シナリオ、扉やかごのアニメーション、通常探索シーンは未実装です。

## 今回の通行条件

H棟の3階足場は、アイリスの部屋の窓と、1階の予備布棚へ降りる外梯子に接続します。通常の階段とは別経路です。窓は本人の了承の札が出るまで通れません。道具を持つサムが外梯子を使うには、足元と固定索を確かめる行為が必要です。ネルの台所は、側窓で用件を伝えるか、修理の立入りを合意してから訪ねます。初期の接続図だけを可通行とみなしません。
