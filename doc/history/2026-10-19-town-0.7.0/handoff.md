更新: 2026-10-18 / town-0.7.0。対象: TomTomYoung/roadonden。

## 制作方針

街の規模感は戸越銀座の商店街と周辺住宅街。現画面は全体マップ、素材はドット絵です。まずこの全体マップで100人・十場面・別解・共同作業・達成後の暮らし・保存・結末を完成させます。その後にMOONを基準としたエリアごとの探索シーンへ進み、必要ならPhaserを検討します。現在はCanvasを継続します。

30棟・327地点、六区間の商店街・裏通り・住宅路。現在の棟数へ全員を押し込む制約はありません。O棟の共用エレベーターは荷物用昇降機と独立した初期経路で、今回C044の往復案内を追加しました。完全な呼出し・開閉扉・定員の設備モデルは未実装です。

## 今回の実装

**動作実装は32人と犬**。前版の26人にC018アルフ、C019ピップ、C022カレブ、C023ローズ、C024ノア、C044ハリエットを追加しました。残る68人の動作と全員の結末は未実装です。100人の基礎シートや配置案を、動作完成に数えません。

- **引継ぎと夜回り**：二人が鐘を何の合図だと思っているかを聞き、管理人室で会うようそれぞれへ伝える。二人は直接話し、帳面の範囲を読み合わせて巡回灯・ベル・帳面を実際に渡す。アルフは自分の寝床へ帰って横になり、眠って達成する。ピップは主人公と一度歩く経路か、訂正図の写しを読む経路で道順を確かめる。その後、本人が独力で一巡し、帳面へ記して別に達成する。通常の巡回を続け、眠った先輩を報告のために起こさない。
- **訂正図と往復案内**：旧待合の誤った掲示と新入口の札を照合し、ハリエットへ伝えて案内を直してもらう。カレブは本人の希望を案内係へ直接話して往復するか、主人公と旧待合から新入口・上階の目印を通って戻る。さらにA棟・B棟・中庭の巡回範囲を実地確認し、原図を訂正して掲示先へ運ぶ。当番用の写しも置き、後からピップへ届けられる。カレブが先に終わった場合、主人公自身を利用者としてハリエットと往復できる。二人の達成をまとめない。
- **隣室の音と休息**：双方の了承を得て、ノアが時計を壁から外して持ち、ローズが隣室へ移る。主人公が了承された短い試奏をする間、二人が時計のない壁の振動と時刻を照合する。今は一曲を通し、その後を休息の時間にする約束を全員が受け入れる。ローズは一曲を弾き切って終了を伝え、約束札を残す。ノアは時計を正しく掛け直し、寝床で休息を続けて達成する。ローズは妨げていないことを確認して別に達成する。

ローズのC057レナの防振材を使う別解は未実装です。アイリスのC034エルシーの予備布経路も残っています。既存の時刻・別室の経路を削ったり、達成を消して後続場面へ呼び戻したりしません。

同行は接続する一区間ごとに、参加者全員を同じ移動行為として進めます。移動中は同行者の会話・現地観察も止め、到着時に全員を移します。直接中断なら出発地点に全員が残り、通常UIの取消しなら今の区間を終えて止まります。保存は残り時間ごと復元します。エレベーターの上下位置を同じ軸に合わせ、共有する乗車資源で相反する運行を重ねません。地図からの移動は空きを待って続けます。

待機を早送りしても遠くの住民の動作で会話ボタンを作り直さないよう、操作欄の更新を現地の状態に絞りました。同行や共同作業は、参加者と設備が空いたときに選べます。案内係は古い掲示の問題を聞くと空の往復を止め、その場で相談を続けられます。

**ドット絵は196点**。建物11、内装32、人物と犬102、小道具51。巡回灯・帳面・訂正図・旧新の案内札・鍵盤・時計・掛け具・約束札・かごの10点を追加しました。アルフとノアの寝姿、振動の表示、同行者二人の移動と乗車を実行状態から描きます。全員の固有アニメーションと音声は未完成。旧53素材は保持しています。

## 起動とファイル

ルートの `index.html` を直接開きます。サーバーやNode.jsは不要です。公開ホスティングURLはありません。`inspector.html` は基盤検査画面です。

- `src/content/nightwatch-and-routes.ts`：引継ぎ、同行による道順確認、独力の巡回、訂正図、案内係の往復。
- `src/content/quiet-neighbours.ts`：時計の取外し、共同試験、一曲の実行、終了の連絡、休息と確認。
- `src/content/journeys.ts`：隣接する経路の行為生成。本人の段階認識は各区間の到着時の観察から更新します。
- `src/content/dinner.ts`：既存の夕食・鍵・茶、共通ヘルパー、歩行と共有する乗車資源。新しい人物は歩行カタログ生成前に登録します。
- `src/content/rooms-and-sleep.ts`：乳児を観測者から除く処理は、今回の手掛かり登録後にも適用します。
- `src/core/engine.ts` / `validation.ts`：移動の同行者全員に出発位置と到着効果を要求し、移動中として扱います。
- `src/game/renderer.ts` / `scripts/make-town-assets.mjs`：描画と画素格子の素材生成。`npm run assets` で再生成。
- `tests/nightwatch-and-quiet.test.mjs`：独立した達成、直接案内と訂正図、往復の順序、途中保存・中断、共同試験、睡眠の後日の観察。

内容版 `town-0.7.0`、保存形式2、保存枠 `roadonden:town:v7:`。v6は `legacy/town-0.6.0.html` と `roadonden:town:v6:` で保持します。v5・v4・三棟版・旧街歩き版も保持し、保存画面から開けます。旧セーブの自動変換はしません。原文と旧素材は変更していません。

開発はNode.js 24以上で `npm ci`、`npm run verify`。ブラウザ検査は `scripts/browser-dinner-check.mjs`、`browser-rooms-check.mjs`、`browser-postal-check.mjs`、`browser-nightwatch-check.mjs`、`browser-check.mjs`。型検査・ビルドに成功し、自動検証は既存71項目と追加9項目の計80項目を確認しました。追加分のうち、案内係への伝達後の待機と同行の開始待ちを直した2項目は修正後に再実行して通過しています。Chromiumの実画面操作は本編15、部屋と眠り5、郵便室4、夜回り・隣室5、検査画面10の計39項目が通過しました。1440px・390pxの日本語表示と、睡眠・案内完了時の描画を目視確認しました。生成HTMLとSVGもコミットします。
