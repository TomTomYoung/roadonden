# 仕様書の入口

策定日: 2026-10-17 JST  
仕様版: 0.1.0  
状態: Phase 2の夕食編試作あり。11人と犬、独立した夕食三経路、通常画面を実装。全100人と公開ホスティングは未完了。詳細は [夕食編の実装状況](dinner-status.md) を参照。

本書群は、選択ページ「ロードンデン街の人々 認識と行動からの再設計」をゲームへ落とすための仕様です。依頼の受注とアイテム納品だけで進める構造に置き換えず、住民が観測し、判断して動き、生活上の目的を実際に果たすところまでを扱います。

## 読む順序

1. [ゲーム仕様](01-product-spec.md): 何を遊ぶか、目的、基本操作、時間、進行。
2. [シミュレーション仕様](02-simulation-spec.md): 認識、行為、情報伝達、同時実行、達成の処理。
3. [データ契約](03-data-contracts.md): 人物、物、行為、知識、共同場面、保存データの記述規則。
4. [街と場面の仕様](04-world-and-scenarios.md): 100人の構成、地理、依存関係、先行実装の具体的な経路。
5. [画面・操作・素材仕様](05-ui-and-assets.md): 画面に見せる情報と、動作を読み取るための素材。
6. [検証・受入基準](06-validation-plan.md): 因果、資源、情報、同時作業、解決順、操作性の確認。
7. [実装計画](07-implementation-plan.md): 技術構成、段階ごとの完成条件。
8. [設計判断と未確定項目](decisions.md): 原案からの継承、今回の補足、調整対象。
9. [ハンドオフ](handoff.md): 現状と、次の作業の着手点。

人物データを作る際は [人物記述テンプレート](templates/resident.md) と [原文一覧](sources/README.md) を併用します。原文には再設計本文とC001〜C100の記述を省略せず収録しています。

## 文書の優先順位と変更

今回のユーザー依頼、以後の明示的な変更指示を最優先します。人物と場面の基準は再設計版です。親ページの旧案を現在の人物表や実行仕様として使いません。

`sources/` は取得時点の原文です。実装向けの追加仕様は本書群と `decisions.md` に記載し、原文を書き換えて決定済みに見せません。矛盾が見つかった場合は、実装で黙って一方を捨てず、判断の根拠と影響する人物・テストを記録します。Pageの後日の更新は自動反映されません。

人物IDの名前空間は `redesign-v1` とします。旧案のC001と再設計版のC001は同一人物だと推定しません。並び替えでIDを振り直さず、共同場面・道具・行為には人物番号とは別の安定IDを付けます。

## 仕様策定時の完了範囲

ゲームの全体仕様、実行規則、データ契約、100人の原文保存、場面間の接続、先行実装、検証基準、ハンドオフを用意しました。100人分の座標・会話全文・行為データ・最終素材の作成や、実装済みであることを意味しません。
