# ハンドオフ

更新: 2026-10-17 / town-0.4.0。対象: TomTomYoung/roadonden。

## 最優先の制作方針

街の規模感は戸越銀座の商店街と周辺住宅街です。現画面は全体マップとして扱い、ドット絵で制作します。まず全体マップ上で100人・十場面・別解・共同作業・達成後の暮らし・保存・結末を作りきります。その後、MOONを基準にエリアごとにシーンが切り替わる通常探索を作り、必要ならPhaserを導入します。現在はCanvasを継続しています。

最初の三棟は街の一角で、完成時の上限ではありません。30棟への拡張も街全体の完成宣言ではありません。人物の登録や空間の追加だけでシナリオを実装済みと数えません。[制作方針](08-world-map-and-scenes.md) と [街の配置](09-town-layout.md) を参照してください。

## 今回実装したこと

三棟・33地点から、**30棟・327地点**へ拡張しました。西口、市場、工房、劇場、郵便坂、東口の六区間を、商店街・店の裏通り・南側住宅路・脇道でつなぎました。各棟の部屋、階段、屋上へ歩けます。既存11人の場所IDと夕食の動線は保持しました。O棟の共用エレベーターは、荷物用昇降機と独立して最初から使える上下移動経路です。案内係のシナリオと運行の描画は未実装です。

**168点のドット絵素材**を適用しました。建物11点、内装31点、主人公と全100人と犬の102点、小道具24点です。二次元の画素格子に直接描き、SVGへ画素の矩形として出力します。人物は待機・歩行2枚・作業/運搬・着席・踊りの基礎6コマ。全100人分の基礎シートがあることと、全100人のシナリオや固有動作の完成は別です。旧53点と生成元は `public/assets/` に保存しています。

地図にドラッグ、ホイール拡縮、街全体の表示、主人公への追従、六区間への表示移動、小地図、場所名検索を追加しました。地図を見る操作では主人公を動かしません。目的地を選んで歩く場合は、接続された通路を順に歩きます。全体表示の枠は街の縦横比に合わせ、画像を非均等に伸ばしません。

**動作実装済みは15人と犬**です。既存C001〜C008、C045、C054、C064に、C009エリアス、C010ドーラ、C011ベス、C025アグネスを追加しました。元の鍵を回収する経路、予備鍵の別解、待合せの伝達、本人による入室と着席、母娘の実際の茶、店を閉めた後の保管箱、帰宅後の鍵の返却まで実装しています。物の所有・所在、情報と同意、本人の目的達成を区別します。

全100人の初期位置と目的地を `resident-placements.ts` へ割り当てました。残る85人の詳細な生活動線・行為・会話は未実装で、地図上の住民としては生成していません。全100人の結末も未実装です。

会話中に住民が歩き出して伝言が失敗する競合を修正しました。会話は相手の在場を短時間予約し、歩行が同じ予約を使います。手を使う作業は並行でき、会話から物理作業を実行することは引き続き禁止しています。行為の参照と規則の順序を事前に索引化し、大きい地図で毎刻検索・整列し直す負担を減らしました。

## 起動・保存・主なファイル

ルートの `index.html` を直接開きます。ネット接続・Node.js・サーバー起動はプレイに不要です。公開ホスティングURLはまだありません。`inspector.html` は基盤検査画面です。

- `src/content/block.ts`：初期三棟の場所定義、全体の地点索引と移動時間。
- `src/content/town-layout.ts`：30棟、六区間、追加の部屋・階段・屋上・街路。描画範囲は7540×2420。
- `src/content/resident-placements.ts`：全100人の初期位置・目的地・動作実装の区別。
- `src/content/dinner.ts`：15人と犬、鍵・茶の追加経路、会話・認識・行為・貸借。旧内部ID `quay` / `school` は参照を保つため残しています。
- `src/game/renderer.ts`：全体マップの描画、カメラ、小地図、画素の拡縮。
- `scripts/make-town-assets.mjs` / `public/pixel-assets/manifest.json`：現在のドット絵生成元と素材台帳。`npm run assets` で再生成。
- `tests/town.test.mjs`：地理・人物配置、鍵の別解、後からの返却、母娘を先に進める順序、所持途中の保存。
- `doc/adaptation/residents-001-100.md`：100人のシナリオ。現行配置は `09-town-layout.md` を優先。

保存形式2、内容版 `town-0.4.0`、保存領域 `roadonden:town:v4:` です。旧三棟版は `legacy/block-0.3.0.html`、旧街歩き版は `legacy/dinner-0.2.0.html`。保存画面から開けます。追加人物や途中行為があるため旧セーブの自動移行は行いません。旧保存領域 `roadonden:block:v3:` と `roadonden:dinner:v2:` を削除・上書きしません。

開発はNode.js 24以上で `npm ci`、`npm run verify`。ブラウザ検証は `scripts/browser-dinner-check.mjs` と `scripts/browser-check.mjs`。結果と未検証範囲は [実装状況](dinner-status.md) を参照してください。生成済みHTMLとSVGもコミット対象です。
