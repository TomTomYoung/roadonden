# ロードンデン — 棟と棟のあいだ

雑居ビルとアパート二棟、共用中庭。廊下の向こうで続く100人の暮らしを観察し、認識と行動の行き違いをほどく探索アドベンチャーです。

現在は **11人と犬が暮らす夕食の試作**を遊べます。33地点を階段と廊下で行き来し、靴の回収、貸し靴、材料の配達から家族の夕食へ進めます。残る用事は食後にも取り組めます。100人全員のシナリオを集合住宅版へ翻案済みで、残り89人の動作は制作中です。

現在の画面は**全体マップの制作途中の一角**です。戸越銀座の商店街と周辺住宅街を規模の基準に地図を拡張し、素材をドット絵へ移行します。まず全体マップ上で全100人と結末までを完成させ、その後、MOONを基準にエリアごとにシーンが切り替わる通常探索を制作します。これらは今後の制作方針です。詳細は [ハンドオフ](doc/handoff.md) に記載しています。

## 遊び方

リポジトリをダウンロードし、ルートの **`index.html` をブラウザで開いてください**。Node.js、サーバー起動、ネット接続は不要です。公開ホスティングURLはまだありません。

- 部屋・廊下・階段をクリック、または方向キー / WASDで歩く。
- 近くの人の名前をクリック、またはE / Enterで話す。
- ＋ / −で自分の周りを拡大・縮小。「全体」で三棟を見る。
- Iで持ち物、Jで手帳、Mで歩いた場所、Escで一時停止。
- 会話・手帳・保存画面の間は時間が止まる。「少し待つ」は同じ世界を4倍速で進める。

スタートはA棟101の管理人室です。二階の201号室にはフィンチ家、雑居ビル一階には食品店と靴修理店、二階には子どもの活動室があります。

手動保存3枠、自動保存2世代、JSON書出し・読込みに対応しています。保存領域が使えない場合は失敗を表示するため、JSONで記録を持ち出せます。**旧・街歩き版のセーブは [legacy/dinner-0.2.0.html](legacy/dinner-0.2.0.html) で再開**してください。新版と旧版の保存枠は別で、新版への自動変換はしません。

## 素材と開発

建物・内装・小道具・人物・犬の53点を編集可能なSVGで用意しています。`public/assets/manifest.json` が台帳、`npm run assets` が再生成です。画像はすべて単体HTMLへ埋め込みます。全100人の固有動作と音、細かな室内自由歩行、実機のタッチ・ゲームパッド対応は未完了です。

Node.js 24以上で `npm ci`、`npm run verify`。TypeScript 5.9.3とesbuild 0.25.11で型検査、自動テスト50件、ビルドを行います。`index.html` と開発検査用の `inspector.html` は生成物もコミットします。

Playwright環境では `node scripts/browser-dinner-check.mjs` で本編、`node scripts/browser-check.mjs` で検査画面を確認します。必要なら `PLAYWRIGHT_MODULE` と `CHROMIUM_EXECUTABLE` を指定します。通常プレイには不要です。
