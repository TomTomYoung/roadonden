# 画面・操作・素材仕様

版: block-0.3.0。現行画面は、雑居ビルとアパート二棟を並べた断面図です。部屋・共用廊下・階段・屋上と中庭を同じ画面で見せ、人物の所在と時間のかかる移動を描きます。旧版の街路・独立家屋・運河背景は `legacy/dinner-0.2.0.html` に保存しています。

## 画面と操作

部屋と階段をクリックするか、方向キー / WASDで接続した道を歩きます。部屋同士を直接飛び移らず、住民も同じ廊下と階段を通ります。＋と−で等比拡大し、主人公の周囲を追います。「全体」で三棟の表示へ戻れます。現在地には棟名・階・部屋番号を表示します。

近くの人物だけが会話一覧に出ます。同じ階の隣室や別階とは話せず、受渡しも同じ操作点が必要です。断面図の見た目は場所の手掛かりですが、遠くの状態を表示しただけで主人公や住民が知識を得ることはありません。Eで近くの人、Iで持ち物、Jで手帳、Mで歩いた場所を開けます。地図には訪問済みの場所とそこから見つけた道を表示します。

会話・手帳・持ち物・保存画面中は時間を止めます。待機は同じ固定更新を4倍で進めます。歩行の中断は現在の区間を歩き終え、次の区間へ進まない操作です。現在は地点内の自由歩行・視線遮蔽・音の伝播を実装していません。

会話には得た情報と実際に提案できる内容だけを出します。手帳は情報源・取得場所と、自分で確かめた達成を記録します。内部ID、未発見の依存関係、全知の達成人数は開発画面へ分離します。持ち物には所持品・数量・持ち主・貸出の約束を示します。

## 素材と再生成

`public/assets/manifest.json` が53点の素材台帳です。ID、用途、状態、元寸法、ファイル、出典を記録しています。全点を本作向けの編集可能なSVGとして作成し、`scripts/make-block-assets.mjs` から `npm run assets` で再生成できます。外部画像の転載やネット読込みはありません。

- 建物5点：A棟、雑居ビル、B棟、中庭、階段。建物は各階の床、壁、共用廊下、手すり、階段室を持ちます。
- 内装20点：管理人室、台所、隣室の台所、食品店、靴修理、活動室、スタジオ、食卓、居室、談話室、集合ポスト、ランドリー、共同工房、小劇場、屋上設備、鉢置場、ペット囲い、中庭、搬入口、階段の家具・設備です。
- 小道具15点：注文包み、外履き、貸し靴、鍋、返却箱、合図札、受け台、荷、食事、紙人形、玩具、囲いの開閉、目隠し、閉店シャッターです。
- 人物12点：主人公と本編11人。各シートは64×80の6コマで、待機・歩行2枚・作業/運搬・着席・踊りを収録。子どもは体格、住民は服色・エプロン・帽子等で分けます。
- 犬1点：64×48の4コマで、待機・歩行・振り返り・靴をくわえる姿です。

すべて元の縦横比を保ち、人物はコマ単位で切り出します。素材を別倍率で引き伸ばしません。`src/game/assets.ts` は生成した参照一覧、`renderer.ts` は表示を選ぶコードです。ビルド時にSVGをdata URLとして単体HTMLへ埋め込み、ファイルを直接開いても動きます。

## 状態差分と現物

移動と行為の経過に合わせて歩行・作業・着席・踊りを切り替えます。持つ品は現物の所持から選び、犬の靴も所在に従います。囲いの戸、合図札、受け台、荷の高さ、料理、目隠し、シャッターは世界状態から描き分けます。描画が消えたことを物の受渡しや作業終了と見なす処理はありません。

現在の53点は集合住宅版の基礎素材です。全100人の固有動作、表情や手の細かな作業、寝具・昇降機・搬入仕切り・送迎便の運行差分、音素材は未完了です。作業姿勢を描いたことを、鍋磨き・修理・食事の全動作が完成した意味にはしません。次の場面追加では、実行条件と読める手掛かりの両方を揃えます。

音のある場面には発生位置と種類の文字表示を併用し、色だけに情報を負わせません。現段階では音を再生しません。ゲームパッド、実機タッチ、文字・演出速度の設定は後続です。
