# 画面・操作・素材仕様

## 1. 画面構成

通常画面は俯瞰寄りの街歩きとします。視界には歩く人、作業している手、物の位置、入口、影、音の発生源を読み取れる密度を確保します。頭上の依頼マークや解決順を示す矢印を、観察の代わりに使いません。接近した時だけ操作対象と可能な基本動作を示します。

会話は話者の名前、発言、選べる話題、提示する物や知った内容を表示します。選択肢に未取得の固有情報を紛れ込ませません。推測を質問として確かめる選択と、確かめた事実を知らせる選択は区別します。会話が成立しない距離や状況では、その理由を伝えます。

持ち物は現物の所在・数量・借用品かどうかが分かる表示とします。所持しているだけで使用中とはしません。対象選択後の取消しは世界を変更せず、確定した受渡しだけが状態を変えます。

手帳は人物、場所、出来事をつなぐ記録です。目撃した事実、誰かの発言、推測を表示上も区別します。未発見の人物名・原因・依存線を埋めません。「確認済みの達成」を通常の未解決一覧から外せます。地図は訪れた場所と知った経路を示し、残された棚や設備は達成人物とは独立して参照できます。

## 2. 初期操作案

PCブラウザを先行対象とします。移動は方向キー/WASD、対象との話す・調べるはEnter/E、取消しはEsc、持ち物はI、手帳はJ、地図はMとします。操作表示を画面内に用意し、キー割当は後から変更できる構造にします。マウスで会話選択やメニュー操作を行えます。

ゲームパッドとタッチでの移動は後続対応候補です。完成済みとして宣伝しません。視点や演出を飛ばしても必要な出来事は処理し、文章を速く送ることで未実行の目的を達成にしません。

音に意味がある場面は、発生位置と種類を示す字幕・振動表現等を併用します。色だけで札や役割を区別せず、形と文字を用います。文字サイズ、音量、演出速度を調整できる方針です。

## 3. 素材の作成単位

素材は見栄えだけでなく、観測可能な手掛かりと状態変化を表します。参照する `presentationId` ごとに、対象の物・人物・状態・観測内容・必要な差分を定義します。必要な絵や音がない時に、シナリオの条件だけ成立している状態を完成としません。

人物は歩行、待機、会話に加え、その人物に必要な行動を持たせます。追う、振り返る、鍋を確かめる、隠す、磨く、押し戻す、支える、合図する、着席、食べる、眠る、片づけ、出発等を用途ごとに用意します。100人全員へ同じ枚数の差分を機械的に要求しません。

背景は街路・屋内に加え、通れる範囲、遮蔽物、操作点、音の接続に対応するデータを持ちます。扉の開閉、札の訂正、橋の位置、荷の受け台、幕、布、受取棚は世界状態から表示が切り替わります。比率を保って配置し、人物や背景を縦横別倍率で引き伸ばしません。

## 4. 先行実装に必要な素材

- 主人公の移動・会話・調べる・持つ・置く・待つ動作。
- ノラの空鍋確認、玄関への往復、買い物、料理、着席。オーウェンの保持、解放、帰宅、食事。キットの工作、持ち帰り、語り。
- ベンと犬の追跡・停止・振り返り・庭への移動、靴を放す動作、庭戸の開閉。
- メイベルの包みの出し戻し・受渡し・戸締まり、ルースの鍋磨きと返却、セリアの食器を片づける動作と休息、レオの足踏み・貸出・閉店・踊り。
- パーシー、タッサ、ラルフの問題中・介入後・達成時の差分。
- 宿の入口、住宅の通り、フィンチ家、庭、市場の店、靴屋、荷下ろし場、学校の工作場所を歩ける仮背景。
- 外履き、貸し靴、注文包み、小鍋、大鍋、焦げた柄、玩具、返却箱、受け台、合図旗、紙人形、食卓の料理の現物表示。
- 足音、犬の動き、鍋と食器、作業音、合図、戸締まり、食卓の環境音。音声台詞は必須にしない。
- 会話、持ち物、手帳、地図、待機、保存・読込、対象選択のUI。

次段階では運河の水位、橋、船、待機札、係留、網、桶、合図と復旧の差分を追加します。劇場等の最終素材はその場面の論理と配置が成立してから制作します。

## 5. 仮素材と完成条件

最初は輪郭・姿勢・動きの差が分かる仮素材を使い、観察で原因を読めるかを検証します。最終素材への置換では当たり判定や状態の意味を変えません。

素材台帳にはID、用途、必要な状態、寸法と基準点、作成状況、参照ファイル、出典・利用条件を持たせます。不要になった既存素材を無断削除する運用にはしません。今回の空リポジトリには素材はまだありません。

画面外へ切り替えた瞬間に作業が完了する、音が消えたので設備も止まったと扱う等、描画都合で論理を変えません。音の停止も、状態の変化を表示した結果として扱います。
