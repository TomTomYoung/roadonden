# 画面・操作・素材仕様

版: town-0.5.0。現行画面は全体マップの制作途中の一角です。現在の範囲では全体マップとしても不足しており、戸越銀座程度の商店街と周辺住宅街へ拡張します。現在は30棟・327地点の建物と街路を並べた全体マップです。部屋・共用廊下・階段・屋上と中庭を同じ画面で見せ、人物の所在と時間のかかる移動を描きます。旧版の街路・独立家屋・運河背景は `legacy/dinner-0.2.0.html` に保存しています。

## 制作する画面と素材

まず、拡張した全体マップ上で全100人と十場面、別解、保存、結末までを完成させます。この段階から、建物・人物・小道具・設備・状態差分をドット絵へ作り直します。177点のドット絵を適用済みです。旧53点の滑らかなSVGは移行元として保持します。全員の固有動作と後続の探索シーン用素材は未完成です。元の比率を保ち、画素単位で輪郭・色・動作を作り、拡大時にも輪郭をぼかしません。

通常探索は、その後にエリアごとのシーンとして制作します。MOONを基準に、主人公が部屋・廊下・中庭・店・仕事場を歩き、人や物へ近づいて観察・会話・調査する画面にします。出入口で接続先へ遷移し、世界の時間・人物・現物・認識・作業途中は継続します。全体マップの拡大表示を通常探索の完成形にはしません。

エリア探索の制作段階でPhaser導入の要否を検討します。詳細は [全体マップ・エリア探索の制作方針](08-world-map-and-scenes.md) を参照してください。

## 現在の全体マップの操作

部屋と階段をクリックするか、方向キー / WASDで接続した道を歩きます。部屋同士を直接飛び移らず、住民も同じ廊下と階段を通ります。＋と−、ホイールで等比拡縮します。ドラッグで表示範囲を動かし、「全体」で街全体、「あなたへ」で主人公への追従へ戻れます。六区間のボタンと小地図は表示だけを移動します。全体表示では街の比率に合わせて表示枠の高さを変えます。現在地には棟名・階・部屋番号を表示します。

近くの人物だけが会話一覧に出ます。同じ階の隣室や別階とは話せず、受渡しも同じ操作点が必要です。断面図の見た目は場所の手掛かりですが、遠くの状態を表示しただけで主人公や住民が知識を得ることはありません。Eで近くの人、Iで持ち物、Jで手帳、Mで歩いた場所を開けます。地図には訪問済みの場所とそこから見つけた道を表示します。検索欄では公開の街の案内図として全地点を場所名で探せます。人物の目的や未取得の情報は表示しません。

会話・手帳・持ち物・保存画面中は時間を止めます。待機は同じ固定更新を4倍で進めます。歩行の中断は現在の区間を歩き終え、次の区間へ進まない操作です。現在は地点内の自由歩行・視線遮蔽・音の伝播を実装していません。

会話には得た情報と実際に提案できる内容だけを出します。手帳は情報源・取得場所と、自分で確かめた達成を記録します。内部ID、未発見の依存関係、全知の達成人数は開発画面へ分離します。持ち物には所持品・数量・持ち主・貸出の約束を示します。

## 素材と再生成

`public/pixel-assets/manifest.json` が177点の素材台帳です。ID、用途、状態、表示寸法、内部の画素寸法、ファイル、出典を記録しています。`scripts/make-town-assets.mjs` から `npm run assets` で再生成します。二次元画素配列に直接描き、同色の連続した画素を整数の矩形としてSVGへ出力します。外部画像の転載やネット読込みはありません。

- 建物11点：初期三棟、追加棟の6種類の外壁、中庭、階段。各階の床、壁、共用廊下、手すり、階段室を描きます。
- 内装31点：既存20種類に、預かり品店、保管室、パン屋、計量、織機、加熱設備、エレベーター、舞台、書庫、印刷、送迎車を追加しました。
- 小道具33点：旧来の注文包み、靴、鍋、返却箱、合図札、受け台、荷、食事、人形、玩具、囲い、目隠し、シャッターに加え、鍵、上着、茶、椅子、郵便物、自転車、木、街灯、鉢を描きました。
- 人物101点：主人公と全100人。各シートは16×20画素の6コマを4倍の64×80で収録します。待機、歩行2枚、作業/運搬、着席、踊りの基礎姿勢です。シナリオ実装人数は23人で、100人分の固有動作が完了した意味ではありません。
- 犬1点：16×12画素の4コマを4倍の64×48で収録します。

旧53点と旧生成元は `public/assets/` と `scripts/make-block-assets.mjs` に残しています。現行の再生成には新しいスクリプトを使います。

すべて元の縦横比を保ち、人物はコマ単位で切り出します。素材を別倍率で引き伸ばしません。`src/game/assets.ts` は生成した参照一覧、`renderer.ts` は表示を選ぶコードです。ビルド時にSVGをdata URLとして単体HTMLへ埋め込み、ファイルを直接開いても動きます。

## 状態差分と現物

移動と行為の経過に合わせて歩行・作業・着席・踊りを切り替えます。持つ品は現物の所持から選び、犬の靴も所在に従います。囲いの戸、合図札、受け台、荷の高さ、料理、目隠し、シャッターは世界状態から描き分けます。描画が消えたことを物の受渡しや作業終了と見なす処理はありません。

現在のドット絵177点は全体マップ用の基礎素材です。旧版の原本を保持しています。全100人の固有動作、表情や手の細かな作業、昇降機・搬入仕切り・送迎便の運行差分、音素材は未完了です。作業姿勢を描いたことを、鍋磨き・修理・食事の全動作が完成した意味にはしません。次の場面追加では、実行条件と読める手掛かりの両方を揃えます。

音のある場面には発生位置と種類の文字表示を併用し、色だけに情報を負わせません。現段階では音を再生しません。ゲームパッド、実機タッチ、文字・演出速度の設定は後続です。

## town-0.5.0の状態差分

枕、舞台用クッション、手紙、梯子、固定索、清掃道具袋、ゆりかご、敷物、呼鈴の9点を追加しました。フィンのシートは成人の立ち姿から、横になった乳児の反応・抱かれた状態・眠りへ置き換えました。ヘスターの寝姿、ビーの茶、呼鈴の接続、窓の了承札、所持中の手紙・枕・道具を実行状態から描きます。細かな手作業の全アニメーションが完成したわけではありません。
