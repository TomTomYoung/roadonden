# 三人の夕食

8人です。家族の合流に、追跡、受取、借用品、休息の問題が絡みます。犬や鍋の問題をすべて夕食の必須条件にはしません。

## C001 ノラ フィンチ

初期の行動様式は、往復と待機です。

望みは、夫と息子に夕食を出し、自分も座って話を聞くことです。犬が持ち去った外履きを探しながら、玄関と空鍋を往復しています。材料はメイベルの店に取り置かれていますが、本人は買いに行く方法に考えが寄っています。

主人公は靴を回収する、レオの貸し靴を届ける、了承を得て材料を運ぶ、のいずれでも進められます。注文の話と空の材料棚が、金銭不足ではなく移動と受取の問題だと分かる手掛かりです。

料理だけでは未達成です。オーウェンとキットが帰り、三人で食べ始めて達成します。家族の食事は以後の問題に再び徴用せず、空鍋と玄関の往復が、湯気と着席へ変わる場面を報酬にします。

## C002 オーウェン フィンチ

手が空いた段階で帰宅でき、夕食の予定を知って家へ向かいます。食卓で話を聞き始めて達成します。後の通船は受け台と岸の係が担い、彼を家から呼び戻す必要はありません。

# 閉じた家

8人です。鍵や戸という物理的な障害と、そこに人がいないと思い込む問題を分けます。直接会うだけで解ける経路も残します。
