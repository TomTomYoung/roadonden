# 実行基盤の実装状況

> この文書はPhase 1時点の記録です。現在の夕食編、保存形式2、通常画面の状況は [dinner-status.md](dinner-status.md) を参照してください。検査画面は現在 `inspector.html` へ分離されています。

更新日: 2026-10-17 JST。対象: Phase 1初版、コンテンツ版 `foundation-0.1.0`。

## 現在できること

100ミリ秒の固定更新を行い、世界の事実、人物ごとの認識、実際の達成、主人公が確認した達成を別々に保持します。規則の選択関数は本人の認識・現在地・合意だけを受け取り、世界全体を引数に取りません。物理的な開始・持続・終了条件は世界状態を検査します。

調査・発言・提案には出来事と取得元を記録し、情報を受け取るのは次の更新です。相手が同じ場所にいなければ発言は届かず、移動途中の調査・会話も拒否します。提案の受領と版ごとの受諾を分けています。観測前の事実を知らないこと、誤った初期認識でも世界の事実そのものを書き換えないことをデータ上で区別できます。

行為は開始・実行・中断・復旧・終了を持ち、最短でも開始の次更新に結果を出します。左右の手、場所、道具、現物、人物、書込み先の資源を一括で確保し、確保できなければ一部も保持しません。既存予約を優先し、新規要求は採番順です。物の移転は一つの候補状態へ適用し、途中の効果に失敗した場合は部分的な受渡しや消費を残しません。

持続条件は更新前と同じ更新で他行為が確定する結果の両方を確認します。設備停止と加工終了が重なる境界で、処理配列の順によって成功させません。中断時には定めた保持資源を残して復旧し、その後に解放します。世界の時刻や既に確定した移動を巻き戻しません。

実行の証拠イベントに対応して達成を一度だけ記録し、本人の問題用規則から通常生活へ移します。画面外の達成は主人公の手帳へ直接出さず、その場で見届けるか、後で本人に尋ねると確認できます。確認記録にも受信イベントが必要です。

完全な現在状態には、実行中・復旧中の行為、現物、予約、情報の配送待ち、認識、合意、再試行時刻、出来事、達成、保留コマンドと採番値を含めます。読込は候補の版・型・参照・数量・収納先の循環・予約台帳・認識と達成の証拠を検証してから置換します。外部ファイルの不正で現在の状態を変更しません。

## 実装ファイル

- `src/core/types.ts`: 基盤初版の型。完成時のデータ契約の全項目ではありません。
- `src/core/validation.ts`: 定義、条件、効果、コマンド、状態、保存の検証。未知の演算子を拒否します。
- `src/core/conditions.ts`: 本人の判断と物理条件の評価を分離。
- `src/core/engine.ts`: 固定更新、情報配送、行為、予約、移動、物、復旧、達成。
- `src/core/clock.ts`: 描画時間の刻みを固定更新へ変換。停止中の実時間を加算しません。
- `src/storage/saves.ts`: 手動3枠、自動2世代、JSON入出力。ストレージ失敗を呼出元へ返します。
- `src/content/foundation.ts`: 本編とは別の3人・4地点・包みと加工材料の検査定義。
- `src/dev/`: 操作と因果を確認する検査画面。内部ID・世界の真実の表示は開発用です。
- `scripts/build.mjs`: 内容を検証し、外部読込みのないルート `index.html` を生成。
- `tests/foundation.test.mjs`: 基盤の自動検査25件。
- `scripts/browser-check.mjs`: 検査画面のブラウザ操作確認10項目。

## 検証結果

`npm run verify` で型検査、25件の基盤テスト、単体HTMLビルドが成功しています。対象は知識の未取得と否定、情報の遅延伝達、未知の情報と遠隔発言の拒否、物の競合、予約の部分確保防止、移動中の保存、受渡しと受領報告の分離、効果失敗の原子性、保持予約と復旧、同一更新での持続条件喪失、再試行、消費の重複防止、達成と確認の分離、提案と受諾、描画刻み独立、コマンド再生、破損保存と保存領域不足です。

Chromium headlessで `file://` から実際の `index.html` を開き、10項目を確認しました。起動時の外部HTTPリクエストとJavaScript例外は0件です。調査、伝達、自律作業、達成表示、手動保存、JSONダウンロード・再読込み、破損JSON拒否、非表示時の停止、保存領域拒否の表示を確認しました。幅1280pxと390pxで確認し、狭い画面に横方向のはみ出しはありません。画面画像も目視しました。

これは検査役の確認です。本編受入基準T01〜T18の合格、本編の遊びやすさ、全100人の到達性、任意順序の詰みなしを保証するものではありません。実際のWindows/Chrome/Edgeとスマートフォンでの操作確認はまだありません。

## 未実装・制限

本編のC001〜C100は原文のまま保存されており、実行データ化は0人です。先行11人と犬、三つの夕食経路、メイベル本人の配達、鍋・貸し靴の返却は次の実装です。検査役の包みの運搬を、それらの代わりに完成扱いにしません。

地図は場所単位です。個々の人物の室内座標、遮蔽物、距離と騒音による視聴覚、自動観測、推論、発言への個別の信用・理解・返答は未実装です。初版の伝聞は命題の認識を更新しますが、受諾は別操作のままです。

物は一つの所在・所有者・整数数量を持ち、所有権を変えずに渡せます。借用台帳、返却方針、積重ねの分割・併合、補充・価格・営業時刻、複数段階の共同場面は未実装です。材料3個は検査用の有限在庫で、完成したゲームの補充設計ではありません。

共同作業の復旧は一段階です。運河の複数段階、支えの置換、移動経路の途中で中断した際の物理的な停止位置、複数地点をまたぐ経路探索は未実装です。現在の移動中断では出発場所に留まり、更新時計は進んだままです。実際の運河や街歩きへ適用する前に拡張します。

保存形式は初版だけです。旧版の移行器、容量や長時間ログの最適化、100人規模の負荷試験は未実施です。`savedAt` の実日時メタデータはまだ持たず、世界内の `tick` を保存します。乱数状態は保存しますが、現行の検査内容は乱数を使いません。

完成素材、音、通常プレイ用の会話・手帳・持ち物UI、キーボード街歩き、公開ホスティングは未実装です。検査画面はこれらを完成品に見せるための画面ではありません。
